# Introducción

Este repositorio contiene materiales de apoyo para la asignatura **Manejo de Datos**, incluyendo notebooks, prácticas, datasets de ejemplo y guías de instalación.

## Objetivo

Desarrollar competencias para el diseño e implementación de soluciones computacionales que permitan almacenar, organizar, procesar y recuperar información de manera eficiente, utilizando estructuras de datos, algoritmos y tecnologías de manejo de bases de datos.

Al finalizar el curso podrás:

* Comprender los principios fundamentales del manejo de datos.
* Identificar y utilizar diferentes fuentes de información.
* Analizar y comparar algoritmos de búsqueda y ordenamiento.
* Diseñar e implementar estructuras de datos para resolver problemas computacionales.
* Comprender el funcionamiento de las estructuras de datos lineales y no lineales.
* Utilizar bases de datos para almacenar, consultar y administrar información.
* Aplicar estándares para el intercambio de información.
* Implementar soluciones utilizando programación orientada a objetos.
* Explicar y justificar la selección de estructuras de datos y algoritmos de acuerdo con un problema específico.

## Temario general

Se cubrirán los temas indicados en el temario oficial de Manejo de Datos.

* Repaso de Python y uso básico de Git (por si no usaste Python en tu curso de Programación)
* Algoritmos de ordenamiento.
* Algoritmos de búsqueda.
* Simulación.
* Estructuras de datos lineales.
* Estructuras de datos NO lineales.
* Manejo de bases de datos.
* Aplicaciones con Python.

## Plataforma y tecnologías

El curso se llevará a cabo mediante Google Classroom.

Se utilizará principalmente Python, Git, Google Colab y VSCode para la implementación de algoritmos y estructuras de datos, así como un sistema gestor de bases de datos para las prácticas relacionadas con almacenamiento y consulta de información. Durante el curso también se emplearán herramientas para el modelado y análisis de datos, según las necesidades de cada unidad. Como aplicación práctica de los conocimientos adquiridos, al finalizar el curso se realizará una introducción a la biblioteca Pandas para el manejo, procesamiento y análisis de datos en Python.
